The APK and Windows installer are built by GitHub (see README-START-HERE.txt) and appear on the repo's Releases page
as "Latest TradeCycle build". Copy TradeCycle.apk and TradeCycle-Setup.exe into this folder to offer them on the website.

NOTE: the Windows installer is about 111 MB, above GitHub's 100 MB file limit, so it cannot live in this folder in the repo.
The website buttons point to the GitHub Release "latest-build" instead. The built files are also included in the full ZIP's downloads folder.
